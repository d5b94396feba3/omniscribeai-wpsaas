# Custom AI Content Generation SaaS (WordPress)

This repository contains the `wp-content` directory and theme/plugin codebase for **[omniscribeai.com](https://omniscribeai.com)**, a custom AI Content Generation SaaS built on WordPress.

## 🚀 Repository Contents

* **Custom Themes**: Custom theme files powering the SaaS front-end and application interface.
* **Plugins**: Active WordPress plugins, integrations, and custom SaaS extensions.
* **Assets**: Front-end build assets and media templates.

## 🛠️ Stack & Technologies

* **CMS**: WordPress
* **AI Capabilities**: Multi-provider AI content generation algorithms
* **Architecture**: WP SaaS framework with custom plugins and themes
